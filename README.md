一款专门用于为各类**证件照片、中级工程师职称证、身份证正反面、营业执照及合同扫描件**添加防盗用、防冒领、防篡改专用水印的轻量级工具。

提供 **桌面 GUI 客户端** 与 **零依赖离线单文件网页版** 双重选择。

---

## ✨ 核心特性

- 🔒 **100% 本地纯离线处理**：无论桌面端还是网页版，所有图片均在本地内存/Canvas 中实时合成，**绝不出网、不上传任何服务器**，从源头确保个人隐私与证件安全。
- 📐 **动态像素测距排版**：采用字体边界动态测量算法，根据文字长度与行数自适应计算安全步长，**彻底杜绝文字挤压、重叠与碰撞**。
- 🎯 **内置经典防盗预设**：一键切换安防资质申报、中级职称评审、身份证业务核验、通用业务办理等常见防盗文案。
- 🔀 **三大经典防盗排版**：
  1. **45° 全屏密集平铺**：满屏交错排列，有效抵御局部裁剪与 AI 图像擦除工具；
  2. **居中斜向粗幅横带**：居中贯穿的带边框粗体警示横幅，视觉冲击力强；
  3. **防伪专用印章框**：右下角双线边框免责声明印章，可压在证件关键编号与签名处。
- ⚡ **无极参数调节**：不透明度（10%~90%）、倾斜角度（-60°~60°）、平铺间距疏密、字体大小缩放、颜色自由选择（防伪红、中性灰、警示蓝等）。
- 📂 **文件夹批量处理**：支持一键选择目录，对目录内所有证件照片全自动批量加水印并无损导出。

## 📁 目录结构

```text
watermark_tool/
├── 双击启动水印工具.bat      # Windows 桌面快捷启动器（双击静默运行桌面客户端）
├── watermark_gui.py          # 桌面 GUI 客户端源码（Python + Tkinter + Pillow）

├── LICENSE                   # MIT 开源许可证
└── README.md                 # 项目使用说明
```

## 🚀 快速使用

### 方式一：双击快捷启动（Windows 桌面）
直接双击运行 [**`双击启动水印工具.bat`**](双击启动水印工具.bat) 即可开启客户端：
- 支持单张图片导入或文件夹批量处理；
- 导出支持 JPG、PNG、PDF 等多种格式。

### 方式二：免安装网页版（全平台通用）
直接双击打开 [**`离线网页版水印工具.html`**](离线网页版水印工具.html)：
- 支持任何现代浏览器（Chrome、Edge、Safari、Firefox）；
- 直接把图片拖拽进浏览器窗口，调节参数后点击【导出并下载】即可。

### 方式三：命令行启动 (Python)
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动桌面工具
python watermark_gui.py
```
